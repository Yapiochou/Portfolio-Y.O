# Portfolio Y.O

Présentation de mon portfolio personnel. Ce site présente mes projets, compétences et moyens de contact, construit avec HTML, CSS et JavaScript.

## Aperçu
Site web statique et responsive présentant :
- Une page d'accueil / présentation
- Une section Projets avec captures et liens
- Une section Compétences / Tech
- Un formulaire de contact (ou lien vers contact)
- Animations et responsive design

## Fonctionnalités
- Design responsive (mobile → desktop)
- Sections claires : Accueil, Projets, Compétences, Contact
- Interactions simples en JavaScript (menus, carrousels, modals, etc.)
- Facilement personnalisable

## Technologies
- HTML
- CSS (Flexbox / Grid, animations)
- JavaScript (vanilla)
- Assets (images / icônes)

## Aperçu rapide (local)
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/Yapiochou/Portfolio-Y.O.git
   cd Portfolio-Y.O
   ```
2. Ouvrir `index.html` dans un navigateur :
   - Double‑clic sur `index.html`

## Structure du projet (exemple)
- index.html              — page principale
- /css/                   — fichiers CSS
- /js/                    — scripts JavaScript
- /assets/images/         — images et illustrations
- README.md               — ce fichier

## Personnalisation
- Modifier le contenu dans `index.html` (nom, bio, liens).
- Mettre à jour les projets dans la section Projets (images + descriptions).
- Ajuster les styles dans `/css/` pour changer les couleurs/typographies.
- Ajouter/éditer des scripts dans `/js/` pour les interactions.

## Déploiement
- Peut être déployé facilement via GitHub Pages (Settings → Pages) ou tout hébergeur de sites statiques (Netlify, Vercel).
- Pour GitHub Pages : créer une branche `gh-pages` ou utiliser la branche par défaut et activer Pages dans les paramètres du dépôt.
